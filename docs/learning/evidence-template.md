# 실험 기록: 제목

> 이 파일을 복사해 YYYY-MM-DD-주제.md로 작성한다. 실행 전에는 미실행으로 표시한다.

- 상태: 미실행 / 재현 / 해결 / 추가 확인 필요
- 날짜·실행 환경·커밋:
- 관련 코드·설계 문서:
- 이번에 이해하려는 질문:

## 가설

왜 이런 결과가 나올 것으로 생각했는가? 비교할 대안은 무엇인가?

## 재현 방법

실행 명령, 합성 데이터, 요청 수, 동시성, warm-up, 서비스/컨테이너 상태를 적는다. 비밀번호와 실제 개인정보를 붙여 넣지 않는다.

## 관찰 결과

| 관찰 대상 | 변경 전 | 변경 후 | 근거 파일·로그 |
|---|---|---|---|
| 예: p95 / DB 쿼리 수 / lag / 중복 저장 수 | 미측정 | 미측정 | 없음 |

반복 횟수와 예상과 다른 결과를 적는다. 기준이 다른 수치를 성능 개선율로 비교하지 않는다.

## 해석과 한계

무엇을 확인했으며 무엇은 아직 모르는가? 단일 브로커·로컬 부하가 운영과 다른 점은 무엇인가? 선택의 비용은 무엇인가?

## 면접 답변

문제 → 선택 → 대안과 비용 → 실제 검증 → 남은 한계를 60~90초 분량으로 적는다.
